A smooth import, every time

  1. Start with the example files. Keep their column headers exactly as they are.
  2. Import the example products first, then the example sales. Use a unique reference for every sale row.
  3. Sales imports reduce current stock. For historical imports, opening stock must include the units you will import as sold.
  4. For sales, blank unit_price or unit_cost uses the current product default. Fill both in for historical sales.
  5. If any row is invalid, the entire file is rejected. Fix the reported row and upload it again.

Existing SKUs and sale references are rejected, so re-uploading the same file does not duplicate your data.
